# Darling — Для нас двоих

Личный сайт-подарок о наших отношениях: история, планы на будущее, фотографии и маленькая игра.

## Страницы

| Путь | Описание |
|------|----------|
| `/` | Главная — приветствие, слайдер воспоминаний |
| `/history` | Временная линия по годам (2021–2026) |
| `/future` | Планы, мечты и желания |
| `/game` | Мини-опрос «для парня / для девушки» с секретом и достижениями |

## Стек

- [Next.js](https://nextjs.org/) 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

## Запуск

Нужны Node.js и npm.

```bash
npm install
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

### Другие команды

```bash
npm run build   # сборка
npm run start   # продакшен после сборки
npm run lint    # проверка eslint
```

## Структура

```
app/
  page.tsx           # главная
  history/page.tsx   # история
  future/page.tsx    # будущее
  game/page.tsx      # игра
  ui/                # слайдер, timeline, анимации, навигация, квиз
  globals.css        # стили и атмосфера сайта
public/images/       # фото для слайдера (slide1.jpg …)
```

## Фото для слайдера

Положи горизонтальные изображения в `public/images/` с именами `slide1.jpg`, `slide2.jpg` и т.д. Список слайдов задаётся в `app/page.tsx`.

## Заметка

Сайт сделан как тёплое личное пространство — не коммерческий продукт.
